# Meus-Progetos

Este repositório foi criado com a ideia de reunir todos os projetos que desenvolvi durante meus estudos em **HTML, CSS e JavaScript**.  
A proposta é servir como uma **biblioteca pessoal de códigos**, onde posso revisar e relembrar conceitos sempre que precisar.  
Apesar de ter deixado de lado por um tempo, ainda penso em expandir este repositório, adicionando muitos outros projetos que já criei e que não estão aqui.

## Objetivo
  - Centralizar meus projetos de estudo em um único lugar.
  - Servir como revisão rápida de códigos e conceitos.
  - Mostrar minha evolução como desenvolvedor.

## Estrutura do projeto
````
  Meus-Progetos/ 
  ├── projeto1/ 
  ├── projeto2/ 
  └── ...
````

## Como rodar
1. Clone este repositório:
   ```bash
   git clone https://github.com/j4yh4ck3r/Meus-Progetos.git

   ```

## Tecnologias usadas
  - HTML
  - CSS
  - JavaScript

## Aprendizados
  - Organização de múltiplos projetos em um único repositório.
  - Revisão prática de conceitos já estudados.
  - Evolução contínua: cada projeto mostra um passo da minha jornada.
  - Planejamento de uma biblioteca pessoal para consolidar meu aprendizado.
